虛擬 Switch 測試工具
====================

這個工具會在電腦上扮成一台開了「網際網路」模式的 Switch，
連到 lan-play 伺服器，用來測試連線，不用每次都開遊戲找朋友試。

它能做的事：
  1. 房間列表：看伺服器上現在誰在開房（跟特斯拉面板的房間列表一樣）。
  2. 封包測試：對某台 Switch 送各種大小的測試封包，看會不會掉、延遲多少。
     能直接看出「大封包送不過去」這種加得進房、但比賽連不上的問題。
  3. 開測試房間：開一個叫「虛擬Switch測試」的假房間，
     在 Switch 的特斯拉面板按「房間列表」看得到它，就代表找房的路線是通的。
  4. 連線狀態：延遲、伺服器在線人數。

它不能玩遊戲，只負責測連線。

--------------------------------------------------
Windows
--------------------------------------------------
1. 把 zip 解壓縮到一個資料夾。
2. 連按兩下 vswitch.exe。
3. 輸入伺服器位址，例如 disappear-n5095.i234.me:11451，按 Enter。
   之後會記住，下次直接按 Enter 就好。
4. 第一次執行時，如果 Windows 防火牆跳出詢問，請按「允許」。
5. 照畫面上的選單輸入數字。

--------------------------------------------------
Linux／NAS（x86_64）
--------------------------------------------------
  chmod +x vswitch-linux-x86_64
  ./vswitch-linux-x86_64                      ← 互動選單
  ./vswitch-linux-x86_64 rooms  -s 位址:11451  ← 直接列房間
  ./vswitch-linux-x86_64 ping 10.13.x.x -s 位址:11451
  ./vswitch-linux-x86_64 host   -s 位址:11451 -t 120

在架伺服器的 NAS 上直接執行最準：
測出來的就是「那台 Switch ↔ 伺服器」這一段，不會混進你電腦的網路。

--------------------------------------------------
封包測試怎麼用
--------------------------------------------------
1. 在要測的 Switch 上叫出特斯拉面板（插件會保持連線 1 分鐘），
   記下狀態欄裡的「虛擬 IP」（10.13.x.x）。
   插件待機中時不會回應，所以一定要先叫出面板。
2. 工具選 [2] 封包測試，輸入那個 IP（或先用 [1] 房間列表，再輸入房間編號）。
3. 約 15 秒後會列出結果和結論。

看結果：
  ・全部 0% 掉包：這條路線沒問題。
  ・小封包正常、1400 或 1472 以上掉光：網路擋大封包或切片封包。
    把兩台 Switch 的 lanplay.ini 的 pmtu 設成 1200，
    再用「-m 1200」參數讓工具照同樣方式重測，確認有改善。
  ・連發會掉：對方網路或伺服器有限速。
  ・完全沒回應：IP 打錯、對方不在網際網路模式、對方待機中，
    或你們連的不是同一台伺服器。

--------------------------------------------------
其他參數
--------------------------------------------------
  -s 位址[:埠]   伺服器（預設埠 11451）
  -u 帳號 -p 密碼 需要登入的伺服器
  -m 1200        用 pmtu 1200 的方式送封包（跟 lanplay.ini 的 pmtu 一樣）
  -t 秒          測試房間開多久
  -v             顯示詳細紀錄
